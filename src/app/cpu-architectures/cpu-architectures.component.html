CPU architectures

A Mac app is built for one or more CPU architectures. Apps built for several at once are called universal (or fat) binaries. The architectures listed for an app are the ones its executable contains.

Good to know

  • To see which architectures an app contains, run file or lipo -archs on the executable inside the app bundle, e.g. lipo -archs Foo.app/Contents/MacOS/Foo.
  • Variants such as x86_64h (Haswell), arm64e (pointer authentication) and ppc64 are recorded under their base architecture.
